# 쓰레드
* 프로세스 내부 실제 실행의 단위
* 한 프로세스에 여러개 존재가능
* 프로세스의 가상주소공간 내부에서 독립적인 본인의 스택을 가지고 나머지는 다른 스레드와 공유

# CreateThread() WinAPI 제공
* 운영체제 내부적으로 사용하는 쓰레드의 구조체를 생성 (내생각)
* 쓰레드 컨텍스트 구조체 생성
* 쓰레드가 실행할 함수와 인자, 스택사이즈를 지정할 수 있음.

# CreateThread() 로 쓰레드를 생성한 경우
```text
RtlUserThreadStart()
\t
```
