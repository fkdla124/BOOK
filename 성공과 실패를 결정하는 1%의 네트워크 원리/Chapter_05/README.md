# 방화벽
* 주로 사용되는 방화벽은 패킷 필터링형 방화벽이다.
* MAC, TCP/IP 헤더쪽 정보를 가지고 필터링한다.
* TCP 3-way handshake 
ACK, SYN 제어비트를 적절히 활용하여 서버쪽에서 나가는 방향, 들어오는 방향 등을 적절히 필터링 할 수 있다. UDP는 이 과정이 없기에 어느정도 감수하고 허용하거나 원천차단한다.
라우터에 내장된 패킷필터링 기능으로도 방화벽으로 사용할 수는 있다. 하지만 메모리가 적어서 로그를 남기거나 하는 데에는 애로사항이 생긴다. 그럴 때는 방화벽용으로 따로 나오는 하드웨어를 사용하는 것이 좋다.
